# Increment 10: version flag - Test List

## Specifications
- `oxus --version` prints `oxus <oxusVersion>` and a newline to stdout, prints nothing to stderr, exits 0, starts no server and reads nothing from stdin
- `oxus` with no arguments starts the MCP server over stdio, as before
- Any other arguments, including `--version` followed by anything, print `usage: oxus [--version]` and a newline to stderr, print nothing to stdout, exit 64 (EX_USAGE) and start no server
- Tests live in a new `oxusTests` target that depends on the `oxus` executable and on `OxusServer`, so they compare against `oxusVersion` instead of a literal that changes every release
- Tests run the built binary as a separate process and check its stdout, stderr and exit status; they need no Spotlight, so CI runs them
- A server reading a closed stdin exits at once with status 0, so tests that must prove no server started keep stdin open: a server would wait, while the flag or a rejection exits on its own
