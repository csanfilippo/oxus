# Increment 4: structured results - Test List

## Specifications
- Tools: `spotlight_query` and `search` both change; inputs, limits and error messages unchanged
- Output schema: object with a required `paths` array of strings, advertised by both tools
- Success: `structuredContent` is {"paths": [...]} in Spotlight's order, plus one text block with the same object serialized as JSON
- No matches: {"paths": []} in both structuredContent and text, isError false
- Errors: unchanged, one text block with the message and isError true, no structuredContent
- Replaces the one-text-block-per-path output of increments 1-3
- Version stays 0.1.0
