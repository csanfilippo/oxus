# Increment 5: folder scope - Test List

## Specifications
- Tool: `search` gains `folder` (string, optional): the folder to search in, including its subfolders; `spotlight_query` keeps searching the whole index
- Accepted forms: an absolute path, `~` alone, or a path starting with `~/`; `~` expands to a home folder the server is given, never read from the environment
- Rejected forms: relative paths (`Downloads`) and other `~` forms (`~alice/Downloads`), as a result with isError saying which forms are accepted
- Blank or non-string `folder`: result with isError, as for `name_contains`
- Filters: `folder` is combined with `name_contains` and `kind` by AND; the folder itself is never a result
- Folder alone is a valid search and matches every indexed file in the folder (`kMDItemDisplayName == "*"`)
- Neither of the three filters: result with isError naming `name_contains`, `kind` and `folder`
- Description: says the scope includes subfolders, which forms `folder` accepts, and that unindexed files cannot be found
- Output, limits and other error messages unchanged
- A folder that does not exist, is a file, is a package or cannot be read returns no paths and no error until increment 6
- Adapter and acceptance tests scope to `/System/Applications`: indexed, not protected by TCC, holds Terminal.app in Utilities, excludes Finder.app
