# Increment 1: spotlight_query - Test List

## Specifications
- Tool: `spotlight_query` replaces `hello`; it is the only advertised tool
- Input: `query` (string, required, raw Spotlight query syntax), `limit` (integer, optional, default 25, minimum 1, maximum 100)
- Output: one text content block per matching file path (POSIX), in Spotlight's order
- No matches: success with empty content
- Limit above 100: clamped to 100
- Limit below 1 or not an integer: result with isError
- Missing, empty, or blank query: result with isError
- Malformed query: result with isError and a message the client can act on
- Unknown tool: protocol error (invalidParams), unchanged
- Truncation signalling: deferred to the pagination increment
- Spotlight is reached through a port; protocol tests use a fake, adapter tests use real Spotlight
- Adapter tests query always-indexed system files (e.g. Finder.app), in their own test target
