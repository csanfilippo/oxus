# Increment 2: search by name - Test List

## Specifications
- Tool: `search`, advertised alongside `spotlight_query`, which stays unchanged
- Input: `name_contains` (string, required), `limit` (integer, optional, default 25, minimum 1, maximum 100)
- Matching: the display name (`kMDItemDisplayName`) contains the text, case- and diacritic-insensitive; "calcolatri" finds Calculator.app on an Italian Mac
- Literal input: `"`, `\` and `*` in `name_contains` are matched literally; `?` is not a Spotlight wildcard and needs no escaping
- Output: one text content block per matching path, in Spotlight's order; no matches is success with empty content
- Missing, blank, or non-string `name_contains`: result with isError and a message the client can act on
- Limit: same rules as `spotlight_query`, tested here only for wiring
- The client's LLM interprets natural language; oxus receives only structured arguments
- Spotlight port and adapter unchanged; acceptance test searches for part of Finder's display name
